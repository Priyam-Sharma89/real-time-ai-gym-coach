# Real-Time AI Gym Coach

An AI-powered gym coaching application that uses
computer vision to analyze exercise movements in real time.

## Features
- Real-time pose detection
- Exercise-specific movement tracking
- Repetition and set counting
- Workout metrics
- Exercise feedback

## Tech Stack
- Python
- OpenCV
- MediaPipe (verify the version used)
- Streamlit
